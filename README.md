# Sample outputs

These files were generated by `python scripts/generate_sample_outputs.py`.

**They use a scripted offline LLM and SYNTHETIC company data** (fictional companies), so they can be
reproduced without API keys. The crew, manager delegation, tools, benchmarking and PDF compiler are
the real code paths; only the LLM answers and the web search are scripted.

For real research output run `python main.py --query "Tech Sector Q3 Analysis"` with your API keys.
The files are then written to `output/` (or `--output-dir`).

| File | Description |
|---|---|
| `market_report.pdf` | Typeset A4 report: banner, sections, Pandas tables, `Page X of Y` |
| `market_report.md` | Markdown version of the same report |
| `metrics.csv` | Collected (synthetic) metrics analysed with Pandas |
| `benchmarks.json` | Per-task timings and the manager's task routing history |
